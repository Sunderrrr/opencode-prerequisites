---
name: grill-me
description: Interviews the user about a plan or an idea, one question at a time with a recommended answer, until the design is clear. Use when the request is vague or before a big change.
---
1. Explore the code first: do not ask a question whose answer is in the repository.
2. Ask ONE question at a time, with your recommended answer and why.
3. Move branch by branch through the decision tree (scope, data, errors, edge cases, tests).
4. When everything is settled, summarize the decisions in a short list and ask "shall we go?".
5. Write no code during the interview.
