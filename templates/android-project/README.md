## Build and tests

Everything goes through the kit's Podman toolchain (`oc-android doctor` for status):

```bash
oc-android gradle assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
oc-android gradle testDebugUnitTest    # JVM tests
oc-android gradle lintDebug            # Android lint
```

## Emulator

```bash
oc-android emulator start --wait       # requires /dev/kvm
oc-android gradle installDebug         # installs on the emulator
oc-android adb shell monkey -p {{package}} -c android.intent.category.LAUNCHER 1
oc-android adb logcat -d -s AndroidRuntime:E   # no crash expected
oc-android emulator stop
```

## Versions

Versions are pinned in `gradle/libs.versions.toml` and verified on 2026-11-04
(real build + tests on the API 36 image). Before bumping them:

```bash
oc-versions --refresh android
```

API 36 image constraint: Compose BOM ≤ 2026.06.01. A newer BOM requires
`compileSdk = 37` and an image built with `oc-android build-image --api 37`.
The Compose Compiler plugin's Kotlin must stay aligned with the one embedded in AGP.

## Structure

```
app/src/main/java/…                    MainActivity.kt, AppInfo.kt, ui/theme/
app/src/main/res/values/               strings.xml, themes.xml (and values-night/)
app/src/test/java/…                    AppInfoTest.kt (JVM test)
```

The Compose theme follows the system light/dark mode. `HomeScreen` displays the title
with the `testTag` `app_title`, reusable in an instrumented Compose test.

## Release

`oc-android gradle bundleRelease` (R8 enabled). The keystore and its passwords stay
out of the repository (`keystore.properties` ignored, environment variables in CI).
